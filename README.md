# Soul - Know your code

A fun app to visualize your coding activity. Pass in your project's folder directory, and Soul will count the lines across your projects, ignoring comments and tracking each language. See your most-used languages and the total number of lines you've written across all projects.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/SurvivalW/Soul.git
cd Soul/
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run soul.py:
```
python soul.py
```
